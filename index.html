Cross-Platform, Parallel-Friendly Memory Allocator [C++]

Designed and implemented a highly efficient memory allocator, leveraging paged data structures, and relying on augmented stack and array components.

This allocator has very strong scaling properties, and its internal representation allows the costs independent from memory access to remain fairly constant as the number of allocated blocks and previously freed blocks increases.

I achieved a speedup of 1.44 times over Microsoft's mimalloc in a high-churn, 10 million operation test with a large working set. This speedup increases further as the peak number of allocated memory blocks grows.

Efficient Hash Table [C++, SIMD]

I designed and implemented a highly optimized, memory-efficient flat hash table in C++ using variable linear probing and SIMD operations.

Experimented with different probing strategies to handle poorly distributed data, and achieved very similar performance for different sets of keys. Achieved comparable or slightly better insertion and lookup performance to tables using Google’s SwissTable layout.

Radio Propagation Plot Digitalization Software [C#, .NET]

I developed image processing algorithms in C# to digitize highly distorted plots using convolution and Fourier filtering. This reduced processing time by over 90%, eliminating many hours of human work for extracting points or tracing over graphs. This strategy allowed for an efficient replacement of the prior low-precision solution of using only 3-5 points per graph and linearly interpolating.

An example image with much less distortion
